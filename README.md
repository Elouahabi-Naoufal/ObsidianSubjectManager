# Subject Manager

A comprehensive academic subject management plugin for Obsidian. Organize your courses, assignments, exams, projects, and study tasks in one place with powerful search, analytics, and template support.

## Features

### Subject Management
- Create and manage academic subjects with codes, names, and metadata.
- Organize subjects by semester or academic year.
- Track credit hours and instructors.

### Assignments & Exams
- Add assignments with deadlines and priority levels.
- Schedule exams with preparation tracking.
- Track completion status and grades.

### Projects & Tasks
- Manage academic projects with milestones.
- Create todo items linked to subjects.
- Bulk operations for efficient data entry.

### Search & Analytics
- Full-text search across all subjects, assignments, exams, and tasks.
- Analytics dashboard with completion rates and workload overview.
- Filter and sort by multiple criteria.

### Templates
- Pre-built templates for lecture notes, assignments, exams, and project tracking.
- Customizable template system for your workflow.

## Usage

1. Install the plugin in your Obsidian vault.
2. Open the Subject Manager dashboard from the command palette.
3. Add your subjects, then create assignments, exams, and tasks linked to them.
4. Use search and analytics to track your academic progress.

## Data Storage

All data is stored in JSON format within Obsidian's plugin data system.

## Installation

### From the Community Plugins directory
1. Open Obsidian Settings.
2. Go to Community Plugins and disable Safe Mode if needed.
3. Click Browse and search for "Subject Manager".
4. Click Install, then Enable.

### Manual installation
1. Download `main.js`, `manifest.json`, and `styles.css` from the latest release.
2. Create a folder named `subject-manager` inside `.obsidian/plugins/`.
3. Copy the downloaded files into that folder.
4. Reload Obsidian and enable the plugin in Settings > Community Plugins.
